Echo TTS

Same FastAPI process as /v1/audio/speech. Maps to JSON (extra_body). Save settings → server file; draft text → browser only.

Text

About the text field

Becomes input. Segment tags like [S1] / [S2] improve pacing; the server normalizes if omitted.

  • Draft: stored in localStorage only — not in prefs JSON.
  • Long copy: use chunking so synthesis stays in speech-sized slices.
  • ! normalization may change lone exclamations (server env ECHO_NORMALIZE_EXCLAMATION).

Voice

About voices

Maps to voice. Must match a stem or folder under audio_prompts/, prompt_audio/, or extra_prompt_audio/ (or base64 — not listed here). Options come from GET /v1/voices.

  • Reload list: rescans server folders after you add files.
  • Quality: cleaner references track better; very short clips vary more.
  • Save settings stores the selected id.

Output

About stream, format & seed

Sets stream, response_format, and optional extra_body.seed.

  • Stream on: incremental audio, lower TTFB. Streaming wav/mp3/opus still buffers for valid headers.
  • Stream off: one-shot; use non-stream steps. Block size follows server non-stream path.
  • PCM: raw s16le 44.1 kHz — browsers rarely play without extra code; use wav/mp3/opus here.
  • MP3: needs ffmpeg on the server.
stream true = incremental; false = one buffered generation.
Non-stream playback & steps

Pick wav, mp3, or opus for the player below. Steps sets extra_body.num_steps for the non-stream sampler (often ~10–40).

Sampler

About CFG & presets

Populates cfg_scale_text, cfg_scale_speaker, cfg_min_t, cfg_max_t. Presets add block_sizes / num_steps when streaming.

Presets: default = balanced; low_mid = fewer steps on later blocks; low = smaller blocks / VRAM; equal = uniform ~10s blocks. Empty preset = server env defaults.

Expert JSON overrides any duplicate keys.

Long text chunking

About chunking

Maps to chunking_enabled, chunk_target_seconds, min, max; rates default from server unless overridden in Expert JSON.

  • Why: splits long scripts into timed slices for stable latency.
  • Target vs min/max: splitter aims near target seconds within bounds.
  • Off: one giant job — risk of OOM or long stalls.
When off, no automatic time-based splitting.
Expert — raw extra_body JSON
How Expert JSON merges

Merged after form fields and preset; duplicate keys here win. Use for speaker_kv_scale, speaker_kv_min_t, speaker_kv_max_layers, custom block_sizes / num_steps, zero-tail tuning, chunk rate overrides, etc.

  • Must be valid JSON object or Generate is blocked.
  • Values pass straight into inference — typos can error or OOM.
  • Saved verbatim with Save settings.
Save / reset · prefs file

Save settings writes echo_ui_preferences.json (override with ECHO_UI_PREFS_PATH). Reset form reloads defaults from GET /echo/ui/meta and clears Expert JSON — it does not delete the prefs file until you save again.
